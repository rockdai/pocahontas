# M0 界面截图

2026-10-26 · iOS / iPadOS 26.5 · iPhone 17 Pro 与 iPad Pro 11-inch (M5)。每台设备 23 张，共 46 张原始 PNG；点击缩略图查看完整尺寸。

截图来自真实 App 和 Ghostty 渲染器，通过 loopback SSH fixture 连接。服务器地址、账号、命令文本均为测试数据；fixture 只回显输入，不执行 shell 命令。截图保留实际布局、系统键盘与系统文件选择器，没有对界面做后期修改。

App 和终端固定为浅色风格，没有深浅色切换。截图时模拟器系统设为深色，用于检查连接表单、终端、键盘、文件选择器和弹窗仍保持浅色。

iPad 文件选择器的侧栏会直接展示浏览位置；iPhone 首次运行时出现的系统键盘提示也保留在粘贴后截图中。

## 重新生成

先按仓库 [README](../../../README.md) 构建 Ghostty 并安装 Python 测试依赖，然后在仓库根目录运行：

```sh
scripts/capture-screenshots.sh
```

脚本启动专用 `127.0.0.1:62224` fixture，分别创建全新的 iPhone / iPad 模拟器，通过 `screenshots` scheme 操作真实界面，再从 XCTest 结果导出原始截图。结束时删除本次创建的模拟器并关闭 fixture；构建日志和 `.xcresult` 保留在 `.build/screenshots.*`。普通 `pocahontas` scheme 不运行截图流程。
